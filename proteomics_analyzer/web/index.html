    Step 3

    Filter, normalise, impute

    Intensities are log2-transformed first. Each choice is recorded in the exported settings file.

    What happens
    1. log2 transform; zeros are treated as “not quantified”.
    2. Proteins without enough valid values are dropped.
    3. Samples are normalised.
    4. Missing values are imputed, assuming they are mostly low-abundance proteins that fell below detection. Imputed values are flagged and counted wherever it matters.

    Database check · step 1

    Which version of the protein did the search see?

    Use this when the same data were searched against a reference protein database and an alternative one, for example a genome translated with a codon read differently. The program finds every position where the two versions of a protein differ and lists the identified peptides that span it. Only such a peptide can tell the versions apart, so it is the evidence.

    Needed only when one FASTA file holds both the standard proteins and the variants (the variants are the entries whose ID contains this text). Leave it as is if you load two files.

    Database check · step 2

    Evidence at each differing position

    A peptide counts only if it spans the position and does not also occur elsewhere in the database. Peptides that do are shown as ambiguous and are not counted.

    How to read this

    “Alternative version seen” means a peptide containing the alternative residue was identified and the reference version was not. It is only as reliable as the search's own false-discovery control, and a single peptide is thin evidence: check the spectra of the peptides that matter. Missing coverage is not evidence against a version, because many positions fall inside peptides that were never identified.

    Database check · step 3

    How much of the proteome was seen?

    Protein coverage is the share of proteins with at least one identified peptide. Sequence coverage is the share of a protein's amino acids that fall inside identified peptides. Both are measured against the reference proteins.
